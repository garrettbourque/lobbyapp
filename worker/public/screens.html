Kiosk

The kiosk starts on the first screen. Every other screen gets a Back button, unless its auto return is set above 0: then it has no Back button and goes back to the start after that many seconds. A screen with auto return at 0 goes back to the start after a minute without a tap. To show the name of the person a visitor notified, put {Person} in a message, like "{Person} has been notified that you're here."
